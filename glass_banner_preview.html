如何导出到 GitHub
GitHub README 不支持 CSS blur，效果需预渲染成图片。打开下面的 banner.html（放在仓库根目录），它会把你的真实图片叠上玻璃效果，用浏览器截图保存为 image/banner.jpg，README 里用 width="100%" 铺满即可。
